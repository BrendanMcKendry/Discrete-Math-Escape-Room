# Discrete Math Escape Room

A 2D educational escape room game built with Godot Engine that teaches discrete mathematics concepts through interactive puzzles.

## About

Navigate through different rooms and solve discrete math challenges including:
- Truth table puzzles (logic)
- Set theory problems
- Affine cipher decryption

## How to Play

1. Open the project in Godot Engine 4.4+
2. Run the project from the editor or export it
3. Use arrow keys/WASD to move your character
4. Interact with objects to trigger puzzles
5. Solve all mini-games to escape!

## Requirements

- Godot Engine 4.4 or higher
- GL Compatibility renderer

## Project Structure

- `Characters/` - Player character scripts and scenes
- `GUI/` - Menu systems and mini-game implementations
- `Levels/` - Room layouts and interactable objects
- `Interaction/` - Interaction system for objects and NPCs
- `Art/` - Sprites and tilesets
